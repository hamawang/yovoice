# yovoice 产品与交互规范

日期：2026-09-29。状态：主导航与跨页交互已实施；下表列出实际交付范围。后续章节保留长期目标，不代表全部能力已经实现。

本规范覆盖整个产品，包括页面之间的往返和数据生命周期。实现按完整用户流程拆分；每次交付都要覆盖空态、操作中、成功、失败、离开后返回，不能只完成一张正常状态的页面。

| 时间轴 | 吸附、边缘滚动、多选、撤销重做、波纹删除、选区试听、增益/淡化/压低、独听/锁轨；重生成自动顺延；分范围 WAV 导出 | 原字幕时间对齐、长篇流式导出、LUFS 测量 |
| 工程恢复 | 主状态损坏或缺失时恢复上一次成功保存的备份；桌面导入/导出含素材的 `.yovoice` 工程副本 | 多代快照、最近删除、云端备份 |

当前后台只有一个活动任务槽，任务弹层展示该槽的状态，不是任务队列。浏览器预览用于验证交互，原生推理、系统麦克风权限和发布安装包需要分别验证。

分段生成后按句保存原音频，生成过程中不再拼接。选中片段重生成使用当前台词和该句演绎的模型及参数，仅替换该片段并重置裁剪，同轨后续片段按时长差自动顺延；其他轨道保持原位置。再次整篇生成新增音轨，已有可播放内容时新轨默认静音。删除片段不删除台词和源文件，已删除片段不会因迟到的生成结果复活。导出按当前可听轨道的裁剪、位置、空隙、重叠与效果合成 24 kHz 单声道 WAV；当前离线渲染限制一小时，后续长篇需求采用流式文件渲染。旧的整篇合并音频继续可用，但不会从波形推测台词边界。

本次回归覆盖新建/取消导入、作品管理、角色保存与放弃、模型页往返、定向角色应用、引用保护、录音取消/试听/保存、版本试听不改正文。保留后续章节作为功能交付时的验收规则。

角色可保存默认演绎及最多 32 种命名演绎，每种演绎独立保存模型和参数；选择、新增及更多操作集中在一行，重命名和删除放在更多菜单。故事按句选择并保存演绎快照；修改该句参数不会改变同角色其他台词或角色库。库中修改、删除演绎不追溯已有作品，重新选角会清除该说话人的旧演绎。语音项目也可选择演绎。

## 时间轴交付规则

采用成熟编辑器的直接操作方式，主工具栏保持单行紧凑；音量、独听和锁定放在轨道设置，次要编辑命令放在剪辑菜单。以下为实际行为，长篇功能说明不进入产品界面或快速上手。

| 能力 | 交互与边界 |
| --- | --- |
| 吸附 | 片段起止边缘吸附到其他片段、播放头和零点；显示参考线；默认开启并高亮；同轨拖动将当前及后续片段作为整体移动，裁剪后续片段按时长差前后移动，保留原有间隙；关闭或按住 Alt 可自由裁剪 |
| 缩放与波形 | Ctrl/Cmd+滚轮以鼠标位置缩放，按钮以视口中心缩放；可适应全部或所选范围；标尺密度和波形细节随缩放变化；裁短片段不收缩视图 |
| 边缘滚动 | 拖动、裁剪和选择到达视口边缘时自动滚动；Escape 取消本次拖动；释放后形成一次撤销 |
| 选区试听 | 拖动标尺选择范围，播放到选区末尾自动停止；剪辑菜单提供所选片段试听及前后一秒上下文试听 |
| 快捷键与多选 | Space 播放/暂停，Delete 普通删除，Shift+Delete 波纹删除，Cmd/Ctrl+C/V/D 复制/粘贴/复制一份，Cmd/Ctrl+I 分割；Cmd/Ctrl 点击增减选择，Shift 点击连续选择，空白拖动框选；多选移动保持相对位置 |
| 撤销重做 | 按钮及 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z、Ctrl+Y；最多保留 100 次时间轴编辑；输入框中的文字编辑使用自身撤销；生成和文件导出不伪装成可撤销操作 |
| 波纹删除 | 仅主动使用波纹删除时合拢所在轨道的已删区间；重叠删除区间只计算一次；普通删除保留空隙 |
| 正文联动 | 点台词定位相关片段，点片段选择对应台词；播放突出当前台词并自动滚动跟随 |
| 音轨音量 | 轨道设置调整整轨音量；不提供片段淡入淡出与手动音量线；旧片段淡化不再应用于试听或导出；源音频不改写 |
| 独听与锁轨 | 独听控制试听及全部导出；锁轨阻止移动、裁剪、删除、插入和定向重生成，仍可调节监听 |
| 背景压低 | 在背景轨设置降低的 dB 数；对可听的生成对白作 80 ms 进入、200 ms 释放的音量压低；导入音乐不触发对白检测 |
| 角色均衡 | 按非静音采样 RMS 统一同一角色的片段增益，并限制峰值；不标称 LUFS 标准化；锁定轨和背景压低轨不参与 |
| 停顿与替换 | 拖动片段间的停顿柄；同轨后续片段同步移动；重生成固定按时长差顺延同轨后续片段 |
| 导出 | 全部、所选范围、单轨或单角色；与试听共用渲染链；检测峰值，默认防削波；关闭防削波且过载时需再次确认；单声道 24 kHz WAV，上限一小时 |
| 恢复与工程包 | 每次落盘前保存上一份有效状态；主文件损坏时保留损坏原件并恢复备份。桌面工程包包含正文、角色快照、音频及剪辑，导入为新身份副本；不包含模型、密钥或全局设置；总量上限 500 MB |

快捷键不覆盖输入框和弹窗操作。恢复备份是一代状态恢复，不保证找回已经永久删除的素材；工程包用于携带完整媒体的独立备份。Windows 文件对话框实现需要实机验收，浏览器回归和 macOS 编译不能替代。

交互参考：[Audacity 轨道与片段](https://manual.audacityteam.org/man/audacity_tracks_and_clips.html)、[Audacity 选区](https://manual.audacityteam.org/man/audacity_selection.html)、[Audacity 播放](https://manual.audacityteam.org/man/playing_and_recording.html)、[Logic Pro 吸附](https://support.apple.com/en-me/guide/logicpro/lgcpf7c0a2ec/mac)、[REAPER 用户手册](https://dlz.reaper.fm/userguide/ReaperUserGuide726c.pdf)。借用选取、拖动、吸附和监听的常见规则，键位以本表实际实现为准。

## 1. 当前问题与设计边界

根据本地代码和现有界面核对：

| 当前设计 | 使用上的问题 | 目标规则 |
| --- | --- | --- |
| 创作、角色库、参考音频库、历史各占一个入口 | 角色和声音的含义重叠，历史与作品的关系不明确 | 按作品、可复用角色、生成音频分工 |
| `Character` 保存参数和试听，`Voice` 保存参考录音 | 用户难以判断创建的究竟是什么 | 角色库统一入口，内部明确区分角色与参考音频 |
| 创作页选择生成版本时同时恢复正文和参数 | 想听旧版本也可能改写当前作品 | 版本仅切换音频；复用参数通过角色或生成音频新建作品 |
| 从角色库应用预设会修改当前作品的整体参数 | 多人作品中不清楚修改了谁 | 应用前必须有明确的目标角色 |
| 角色编辑器的关闭动作可能保存；参考音频编辑器显式保存 | 用户无法预期关闭的结果 | 作品自动保存，角色编辑显式保存；关闭不暗中发布修改 |
| 生成与下载共享当前活动状态 | 一个任务容易影响其他页面的可用性 | 任务有归属，限制只作用于真正冲突的操作 |
| 字幕按顺序生成合并音频；时间轴支持多轨试听 | 导入时间码容易让人误以为已同步配音，试听容易被误认为可导出 | 只展示已实现能力；对齐和混音导出各自验收 |

依据：`web/src/app/app.tsx`、`web/src/shared/workbench.ts`、`web/src/features/library/`、`web/src/features/settings/settings.tsx`、`internal/workbench/workbench.go`、`README_zh.md`。

长期设计先固定对象含义、保存边界、任务归属和恢复规则。当前不增加云同步、团队协作、商城、插件中心等没有明确需求的入口。

## 2. 用户需要理解的对象

| 对象 | 含义 | 修改影响范围 |
| --- | --- | --- |
| 作品 | 一次内容创作，包含正文、说话人、生成结果、时间轴 | 当前作品 |
| 角色 | 可复用的发声配置，可来自声音设计或音色克隆，包含模型与必要参考音频 | 保存修改只更新角色库，已有作品不自动变化 |
| 参考音频 | 用于克隆等任务的录音及其转写文本 | 使用此素材的新操作；已生成音频不变化 |
| 说话人 | 作品中的叙述者或人物，拥有头像、名称，可使用角色的参数快照 | 此说话人的所有台词；已生成结果标记待更新 |
| 台词 | 有稳定身份的一段正文，归属于一个说话人 | 此台词；不因排序变化丢失音频关联 |
| 生成版本 | 某次输入和参数产生的音频及输入快照 | 内容不可原地覆盖，新生成成为新版本 |
| 音频片段 | 时间轴上对某个生成版本或导入音频的使用 | 裁剪、移动、分割只修改片段 |
| 任务 | 一次生成、下载、导入处理或导出操作 | 明确归属到作品、角色或模型 |

关系：作品包含说话人与台词；说话人使用角色参数快照；台词产生生成版本；时间轴使用音频片段。仅语音生成作品提供本项目历史版本；故事通过时间轴管理片段，不提供历史版本或跨作品生成音频汇总。

可保存、选择和复用的发声配置统一称为“角色”。“说话人 1”表示作品内的台词归属，可在“说话人设置”中命名为“旁白”“小林”等并分配角色。“参考音频”仍是录音素材；“声音设计”“声音参数”描述生成能力，不是另一类角色资产。

将角色与参考音频收进同一个声音库入口时，保留原有 ID、录音、试听及引用，不把两种底层数据强行合并。仅有参考录音的旧条目继续作为参考音频管理，不能伪装成已经配置完成的角色。

## 3. 全局导航和页面层级

左侧导航固定为：

```text
新建作品（故事配音 / 语音生成）
故事配音
语音生成
声音库
最近作品（独立区域，可折叠，最多 5 个，只负责打开）
底部：任务状态 · 设置
```

“创作”是打开作品后的编辑页面，不再与“作品列表”并列成为另一个意义不清的入口。角色创建放在角色库内，也可从角色选择器进入。

| 页面 | 内部页签或分区 | 主要任务 |
| --- | --- | --- |
| 故事配音 | 故事列表；含旧字幕作品 | 新建故事、导入字幕、多人台词与音轨编排 |
| 语音生成 | 语音作品列表 | 单段生成、项目内历史版本管理 |
| 声音库 | 角色 / 参考音频 | 制作、试听、管理复用资产 |
| 设置 | 通用 / 模型 / 引擎 | 应用偏好、模型资源、运行诊断 |
| 作品编辑 | 正文、角色参数、可调整高度的时间轴 | 内容制作、生成、编排、导出 |

任务状态用轻量弹层列出当前任务，不新增常驻一级页面。当前设置内容仍用三个页签；存储维护和诊断可以在现有分区内组织，内容真正增多后再拆分。

页面用于需要持续工作的对象；抽屉用于查看列表条目详情；弹窗用于选角色、确认删除等短操作；头像弹层用于切换角色。不出现弹窗内再套一个完整编辑器的多层结构。

导航返回规则：

- 切换一级入口保留各自搜索、筛选、排序、滚动位置；搜索结果数和总数明确区分。
- 回到作品保留所选台词、光标、时间轴高度、缩放和播放头；播放器保持暂停，避免突然出声。
- 从作品打开角色库、创建角色或安装模型，保留来源作品和目标角色；完成后提供明确的“返回《作品名》”，不自动抢走当前页面。
- 只在首次进入无历史状态时使用默认页签。重启恢复最近工作位置，但不自动开始录音、试听或推理。
- 侧栏只标记当前位置，作品切换与一级入口切换使用同一返回规则。

## 4. 作品页与新建流程

作品列表显示名称、类型、更新时间和确有意义的状态，如“有修改未生成”。技术模型名不占主要位置。点击卡片的头像、标题、摘要、创建时间或留白均进入编辑；更多菜单独立处理重命名、复制、删除，语音卡片另提供历史版本。标题仍支持 Enter 和空格打开，菜单操作不触发进入作品。批量模式由明确的选择入口进入，不能把普通点击同时解释成打开和多选。

顶部“新建作品”展开两项紧凑菜单：故事配音、语音生成。分类列表的新建按钮直接创建对应作品，不再选择类型，不附加解释。

| 类型 | 首屏 | 主要操作 |
| --- | --- | --- |
| 故事配音 | 台词、说话人与时间轴 | 添加台词、导入字幕、分配角色、生成及编辑独立片段 |
| 语音生成 | 正文和角色参数 | 生成语音，通过“历史版本”查看、试听和管理本项目结果 |

字幕是一种故事导入方式，不是第三类作品。旧 `subtitle` 类型兼容归入故事，原有内容与音频保留。故事不展示历史版本；旧故事的整篇音频作为时间轴片段保留。声音库共用角色与参考音频，角色资产命名不变。

- 新建在用户完成起点选择或首次输入后落盘，取消文件对话框不留下空作品。
- 粘贴长文本保留段落；把多段拆为多人台词需显式操作，不能猜测每一段是不同人。
- 从字幕创建默认新作品。已有作品内导入需要明确“新增作品”或“追加台词”；替换正文单独确认。
- 字幕选中文件后直接创建作品，不再展示预览确认弹窗；解析失败显示可操作的错误，不创建空作品。无说话人标记统一归入一人，允许手动分配，不能声称自动辨识了真实人物。
- 顺序配音和原时间对齐区分能力。对齐实现前只提供顺序配音；时间码可显示，但不承诺音频时长匹配。
- 删除作品说明是否保留生成结果与共用素材。默认保留共用资产；提供可恢复删除后才使用“移到最近删除”的文案。
- 复制作品得到独立正文和参数；音频可以安全复用引用，编辑副本不能改动原作品。

## 5. 角色库：创建、管理与应用

### 5.1 列表与详情

角色列表每项只露出头像、名称、必要的来源或语言标签、试听和更多操作。单击名称打开详情；播放按钮只试听；“使用角色”才应用。库内头像是试听入口时要有播放标记，避免与正文中“头像切换角色”的含义混淆。

搜索覆盖名称和用户标签，筛选与搜索可以清除。无角色时显示“创建角色”；搜索无结果显示“清除筛选”，不能误导用户重新创建资产。

详情优先显示试听、角色用途和参数摘要，模型依赖、参考音频和使用此角色的作品放在次级区域。删除受依赖约束时显示具体使用位置，并可跳转处理。

### 5.2 创建与编辑角色

点击“创建角色”直接进入统一的角色编辑页，不预先选择设计或克隆。所选模型决定可用的生成方式和参数；同时支持两种方式的模型在编辑页内切换。

1. 配置声音描述或参考录音。
2. 输入试听文本，点击“生成试听”。试听文本不会成为某个作品的正文。
3. 比较候选试听，选择满意的结果。
4. 命名并“保存角色”。从作品进入时另有“保存并用于〔角色名〕”。

- 试听结果在角色编辑上下文中管理，不挤进普通作品的生成音频。
- 参数改变后旧试听仍可播放，标注“参数已修改”；失败保留此前成功试听。
- 允许未试听就保存有效配置，列表显示“尚无试听”；缺少必填参考音频时就地提示，不能保存为可用角色。
- 编辑已有角色明确“保存修改”“另存角色”；关闭未保存编辑时提供保存、放弃、继续编辑。字段错误只能阻止保存，不能把用户困在页面内。
- 修改全局角色不静默覆盖作品角色。作品中显示“角色有更新”，由用户选择应用新版；项目内修改参数也不反向修改角色库。
- 更换生成方式或模型前保留原配置。若存在不支持参数，先说明影响，不能无声清空参考素材或角色配置。
- 从全局库使用角色：有明确来源角色就返回并应用；没有目标就选择作品及角色，或创建文本配音。按钮不能作用于隐藏的“当前作品”。

### 5.3 参考音频页签

- 支持导入和录音，显示名称、时长、转写文本摘要、来源。试听、编辑元数据、裁剪、替换和删除分别操作。
- 导入先检查解码和时长，成功后才成为正式素材；批量导入逐项报告成功与失败，不因一个坏文件撤销全部。
- 录音前说明正在使用的麦克风；录音中显示时长、停止、取消。拒绝权限给出系统设置入口，设备断开保留可恢复的录音部分。
- 停止录音后可试听再保存。取消不留下无名素材；录音中关闭先提供“停止并保留 / 放弃录音 / 继续录音”。
- 裁剪默认另存，不修改被其他角色引用的原始录音；不满足当前模型时长要求时直接给出裁剪入口。
- 选择器复用角色库的搜索、试听和状态规则。选择不等于应用：点击“用于〔角色名〕”确认；取消保留原选择。
- 在选择器内创建的角色或音频，只有明确保存才进入库；如果已保存，随后取消应用不删除该资产。

## 6. 作品编辑：选择范围与细节

正文、角色参数、时间轴是同一作品内的三个区域。右侧区域根据选中对象显示内容，标题必须回答“现在改的是谁”。

| 动作 | 行为 | 影响范围 |
| --- | --- | --- |
| 点击台词文本 | 定位光标，右侧显示该角色头像、名称与声音参数 | 修改角色参数影响该角色所有台词 |
| 点击台词头像 | 打开角色选择，切换后右侧同步 | 只改变这句的角色归属 |
| 点击“说话人设置” | 管理说话人名称、关联角色、排序、合并和移除 | 当前作品 |
| 点击末尾新增区 | 新建空台词并聚焦，默认上一句角色 | 当前作品 |
| 点击时间轴片段 | 选中片段；拖动主体移动，拖动两端裁剪；点击轨道空白或按 Esc 取消选中 | 磁吸裁剪保持起点并带动同轨后续片段，拖回边缘可恢复；拖动中按 Esc 取消本次裁剪 |
| 返回正文选中台词 | 右侧恢复对应角色参数 | 当前角色 |

删除有台词的角色时必须先选择替代角色；合并角色一次性完成，可撤销。更换某个说话人使用的角色不重置其他说话人。

目标键盘规则：Enter 在光标处拆成下一条台词并继承角色；Shift+Enter 在本条内换行；空白条目按 Backspace/Delete 删除并聚焦相邻条目。中文输入法组词时不得触发拆分或删除。非空台词在边界退格不直接删除整句。

文字选择时 Delete 只删除文字；时间轴获得焦点且片段被选中时 Delete 才删除片段。Space 只在非输入控件中切换播放。提供可发现的快捷键说明，不能要求用户记住隐藏手势。

台词默认紧凑排列，头像对齐首行文字。选中用轻边框或指示，不铺大块灰底、不加阴影。时间码默认隐藏，按需开启。导入字幕、说话人设置、显示时间统一在正文底部；名称不显示无意义计数。

声音参数分层：角色选择与语速等常用项优先，模型选择次之，采样等高级参数折叠。模型不支持的能力明确说明原因；参数数量不能迫使正文变窄到无法编辑。

主按钮按状态显示“生成语音”“生成待更新台词”“生成中…”。单句的更多菜单包含生成、重试、版本、删除；右键不是唯一入口。暂未实现按句生成时继续使用真实的整篇生成按钮，不显示虚假的局部进度。

## 7. 时间轴与导出

- 音轨工具栏提供撤销、重做；支持 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z，Windows 另支持 Ctrl+Y。一次拖动作为一步，取消拖动不入栈；新编辑清除重做分支。当前作品单次编辑会话保留最近 100 步，重新打开后清空；输入框保留文字自身的撤销行为。
- 默认没有占位音轨；“新增音轨”位于左侧控制栏的最后一轨下面，不吸附面板底部。每轨的“音频”按钮与片段同行，紧跟末尾，空轨从起点开始。
- 点击“音频”展开“上传音频”；语音项目另有“从历史版本添加”。上传直接选文件，本项目历史可搜索，选中后追加到当前轨末尾；取消不改变音轨。上传素材随作品保存，不混入生成音频或参考音频库，同样支持裁剪、分割、移动和混音导出。当前单文件上限 20 MB、最长一小时。
- 时间轴默认 100% 一屏约十秒，长作品横向滚动；新增片段保持已有片段的显示比例。“适应完整音轨”由用户主动触发，支持放大选区与缩放时保持光标位置。
- 默认高度仅预留一条音轨；播放栏、标尺、音轨与新增行采用紧凑高度，片段保留可辨识的波形空间。顶部拖柄可调高度，并支持键盘调整和收起；单轨播放器与多轨编辑器分别记住手动高度，列表内的紧凑试听不写入高度偏好。折叠不删除轨道。
- 标尺不显示额外滑条，点按或用方向键移动播放头；左侧只显示静音和删除操作，不显示轨道名称。点片段或轨道空白定位播放头；点正文台词定位对应片段并滚动到可见处；拖动片段才移动。分割发生在选中片段内的播放头位置，无效位置解释原因。
- 片段、轨道、原始音频分别命名。删除片段不删除源文件；删除轨道可撤销；删除被引用的源文件先处理依赖。
- 音量和静音作用范围可见。轨道静音不等于输出设备静音；播放速度与作品导出速度分别定义。
- 生成新版本不自动覆盖用户剪好的片段。提供“替换所选片段”，时长变化时自动顺延同轨后续片段。
- 字幕对齐实现后必须保留原时间码，音频超出原区间时标记冲突。不能静默截断语音或把后面字幕整体挤走。
- “生成”产生音频版本，“试听”播放当前选择，“导出”写出交付文件。三种动作使用独立文案。
- 导出区分选中音频、整篇顺序配音和时间轴混音；只有已实现并验证的选项可用。当前多轨仅试听时不能把单条音频下载包装成作品导出。
- 导出前可见范围、格式、文件名和位置；有未生成内容时提供生成缺失内容或显式使用现有音频。不得静默省略台词。
- 导出完成可播放、打开目录；覆盖同名文件使用系统确认。导出失败保留编辑状态和之前成功的文件。

## 8. 生成音频与版本

只有语音生成项目提供“历史版本”按钮。历史页明确显示当前作品名，仅列出本项目的整段生成结果，可搜索正文、试听、重命名、删除或保存参考音频，并返回原作品。取消跨作品汇总入口。故事不展示历史页或版本选择器，结果作为时间轴片段编辑。原有源文件不因导航调整而删除，下载任务和角色试听不进入语音历史。
| 操作 | 规则 |
| --- | --- |
| 单击记录 | 展开详情，显示来源作品、生成时间、状态及参数摘要 |
| 点击播放 | 只播放音频，不改任何正文或参数 |
| 返回作品 | 返回当前语音项目，保留正文和参数 |
| 采用此版本 | 切换作品使用的音频引用，不恢复正文 |
| 基于此版本新建 | 创建独立作品，保留结果来源 |
| 保存为参考音频 | 从具体生成音频的操作菜单进入，确认名称与原文后保存到参考音频库 |
| 删除结果 | 展示引用关系；被时间轴使用时定位引用，不直接造成缺失片段 |

生成音频列表展示成功生成的音频。生成失败和运行进度属于任务状态，不伪装成音频条目。后续任务记录应区分成功、失败、已取消、已中断；“清除任务记录”不删除音频，“删除音频”明确影响文件与引用。分页或加载更多不能丢失筛选和当前试听位置。

## 9. 设置的三个页签

| 页签 | 内容与交互 | 跨页规则 |
| --- | --- | --- |
| 通用 | 界面语言、网络代理；代理编辑校验后提交，失败保留输入并允许恢复 | 界面语言不改变作品语言；代理变化不暗中中断现有任务 |
| 模型 | 按模型家族组织版本与精度，显示能力、体积、已安装状态、下载与删除 | 从角色或作品进入时定位缺失模型，记住返回目标 |
| 引擎 | 设备选择、运行环境安装与修复、日志和诊断 | 正在生成时不能切换其运行设备；其他不冲突偏好仍可编辑 |

模型下载状态完整包含等待、下载、校验、安装、已就绪、暂停、失败。下载字节达到 100% 后仍显示“校验中”，不提前宣告可使用。失败提供重试及具体原因，重试优先续传。

移除模型前列出使用它的角色与作品；说明以后需要重新下载才能重新生成，已有音频可播放。只删除应用管理的模型文件；外部导入文件区分“从列表移除”和“删除文件”。

更改模型目录明确区分使用已有目录与迁移文件。迁移显示空间检查和进度，失败保留旧路径，完成前不能删除旧文件。设置保存失败显示在对应字段，不把整页变为错误。

修复引擎或下载模型后，由用户点击“返回并重试”；不能在后台自动执行之前失败的长任务。诊断提供版本、设备、错误阶段和可复制摘要，默认不包含正文和录音内容。

## 10. 全局任务、播放与反馈

### 10.1 后台任务

- 每次任务绑定发起对象及输入快照。切换 Tab、改名、编辑内容不会把结果放到另一个作品。
- 生成过程中允许编辑；修改后的台词标为待更新。旧任务成功只对应旧输入，不把新文字标成已生成。
- 同一输入重复点击不重复提交。单推理任务运行时提供等待或明确忙碌原因；不必立即支持并行推理，但 UI 不得假装所有无关操作都冲突。
- 长任务允许离开页面，任务状态入口显示简要进度。取消生成不删除之前成功的音频；暂停下载保留已下载内容。
- 多句生成部分失败时保留成功项，支持定位失败句和重试；整段生成尚无逐句结果时如实报告整段失败。
- 重启后把未完成任务标为已中断并提供重试。失败信息留在对应记录，不在每次打开应用时弹成新的全局错误。
- 退出应用时仅对仍会被终止的任务、录音或未保存修改提示影响，不为已经保存的正文反复确认。

### 10.2 播放规则

全局同一时刻只有一个播放来源。库内试听暂停作品播放；切换页面停止离开页面的试听，保留作品播放头。关闭试听不会自动恢复作品播放。开始录音先停止全部播放。

播放、暂停、加载、解码失败、资源缺失状态可辨认。音频播放失败不撤销已有生成成功记录；提供重新加载或查看文件，而不是自动重跑生成。

### 10.3 错误与通知

| 情形 | 展示位置 | 下一步 |
| --- | --- | --- |
| 字段校验失败 | 字段下方 | 修改或恢复原值 |
| 某一台词生成失败 | 台词状态和任务详情 | 重试、查看原因 |
| 导入音频无法解码 | 导入项旁，包含文件名 | 更换文件、查看详情 |
| 多段合成工具失败 | 该生成任务，标明“合并音频失败” | 重试或复制诊断；不能归咎输入录音损坏 |
| 素材被移动或删除 | 对应资源与引用位置 | 重新定位或替换 |
| 保存失败、磁盘满 | 当前作品持久提示 | 重试、释放空间、另存恢复副本 |
| 普通操作成功 | 短提示或控件状态 | 有需要时提供撤销 |

通知关闭是已读行为，不等于清除任务结果；再次收到同一状态不能重复弹出。后台失败只提示一次并指向任务，不用大横幅持续挤压所有页面。技术详情可展开复制，主要文案描述真实失败阶段。

## 11. 保存、撤销、删除与长期数据安全

- 作品正文、角色分配、参数、时间轴自动保存；页脚区分“保存中 / 已保存 / 保存失败”。收到写入成功才显示已保存。
- 角色及参考音频元数据使用显式保存；裁剪与导出产生新结果。界面偏好立即保存，路径迁移等有副作用的动作单独提交。
- 每个作品有独立撤销历史。文字、拆分/合并台词、角色分配、片段编辑可撤销；下载、生成、导出用取消或版本管理，不伪装成可撤销文件操作。
- 保存失败不能丢掉内存编辑；切换页面、退出和恢复都要处理未落盘内容。自动保存不能替代撤销或版本恢复。
- 删除引用检查覆盖作品角色、全局角色、任务快照和时间轴。已生成音频仍可用不等于相关参考素材可以无提示删除。
- 先实现有依赖说明的安全删除；有可恢复存储机制后再提供最近删除。永久清理展示范围、空间和不可恢复影响。
- 长期作品包应包含正文、角色快照、被使用的素材及来源信息；模型权重不默认打包。缺少模型不阻止阅读和播放。
- 数据格式有版本，迁移前保留恢复副本。未知参数保留；版本不支持的功能明确标记，不能打开再保存就静默丢失。
- 台词需从数组位置升级为稳定 ID 后，才能可靠关联单句版本、任务和时间轴；此规则在实现关联功能时落地，不提前建设通用工作流框架。

## 12. 统一视觉与可访问性

- 统一页面标题、正文、辅助文字、时间码四级字阶；标题、首行内容与侧栏对应区域遵循同一垂直基准。
- 控件只保留常规与紧凑两档；相邻按钮、选择器和输入框对齐。使用现有 Astryx 组件与令牌，不另建一套视觉系统。
- 列表用于密集资产和任务；独立卡片仅用于真正独立的概览。列表行不为一两个字段增加多层边框。
- 主色表达当前操作和选择，红色只表达错误或删除；角色头像颜色保持稳定，同时保留名称，不能只靠颜色识别。
- 悬停可显示次要工具，但键盘聚焦和更多菜单也能访问。图标按钮有可访问名称，焦点可见，弹层关闭后焦点回到发起控件。
- 右侧面板和时间轴可收起；窗口变窄时优先保护正文，参数改为可展开面板，不能把各列等比例挤小。
- 界面缩放、长中文名称、英文文案、双向文字与系统减少动态效果设置都纳入检查；紧凑不等于减少到无法点击。

## 13. 必须贯通验证的用户流程

| 流程 | 验收条件 |
| --- | --- |
| 新建文本作品 → 选角色 → 缺模型 → 设置下载 → 返回生成 | 正文、目标角色与光标不丢；下载完成不抢页面；结果归原作品 |
| 故事某角色 → 创建角色 → 试听失败 → 调整 → 保存并应用 | 失败不留下普通作品垃圾记录；只改变目标角色；其他角色不变 |
| 导入多人字幕 → 改角色 → 新增/删除空句 → 生成 | 未标记字幕不猜人物；新句继承前句；输入法正常；时间能力说明准确 |
| 生成中去角色库试听 → 回作品 → 查看结果 | 不同时出声；任务持续；返回不自动播放；编辑修改仍标待更新 |
| 试听旧版本 → 回当前版本 → 从生成音频保存参考音频 | 版本切换不修改正文和参数；保存的素材与生成结果独立 |
| 生成结果 → 时间轴剪辑 → 重新生成 → 替换片段 | 仅指定片段替换；自动顺延同轨后续片段；源音频不被破坏 |
| 删除已引用角色、参考音频或生成音频 | 显示影响位置；无静默断引用；取消后所有状态不变 |
| 保存时磁盘满 → 切页 → 重启恢复 | 不误报已保存；用户有恢复路径；已有项目文件不被坏写覆盖 |
| 关闭有任务的应用 → 重启 | 说明会终止的操作；标识中断，旧错误不伪装新失败 |
| 在不同语音项目间查看历史 | 仅展示各自版本，不混入故事片段、其他项目或已删除项目结果 |

首批交付应贯通前三条流程，并同时落实选择不改数据、清楚的保存语义、任务归属和依赖安全。单句版本比较、复杂替换策略与长篇导出随后按完整流程交付，不能仅增加按钮。

每个新功能进入开发前补齐：入口、操作对象、影响范围、默认动作、进行中状态、取消、失败恢复、离开后返回、键盘方式、依赖删除、旧数据兼容，以及一条端到端验收流程。规范随功能更新；未实现目标持续标记，禁止把规划能力写成已有能力。

界面文案只保留名称、状态、必要规格和可执行的错误反馈。不给常规操作配功能介绍或重复说明，不用确认弹窗重复用户刚刚选择的动作；删除、覆盖和未保存内容等有实际后果的操作保留确认。
